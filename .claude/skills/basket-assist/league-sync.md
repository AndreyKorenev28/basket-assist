# Проверка синхронизации с лигой

Данные лиг читаются через адаптеры платформ (`src/basket_assist/sources/`: `mtgame` — АБЛ, `infobasket` — МЛБЛ) из открытых
JSON API; что и откуда — `docs/data-sources.md`. Синхронизация сравнивает данные лиги с базой и пишет изменения
(`change_event`: перенос, смена времени, назначено время, новый матч, дозаявка/отзаявка).

## Расписание синхронизации (бот на сервере сам)
Ночная полная (03:00–04:00 МСК), ср–пт — ежечасно, через ~3 ч после матча — результат. Сайты лиг опрашиваются экономно —
не запускай синхронизацию в цикле.

## Проверить
1. **Лог сервера:** `journalctl -u basket-assist --since '-1 day' | grep синхронизация` — у каждой лиги есть строки без
   `не удалась`. Ошибка синхронизации: `[<лига>] синхронизация (...) не удалась: <причина>` — парсеры падают громко.
2. **Вручную на сервере** (тот же код и база, что у бота):
   ```
   ssh -i ~/.ssh/basket_assist_vps $(cat deploy/host.local) "cd /opt/basket-assist && runuser -u basket -- env \
     DB_PATH=/opt/basket-assist/data/basket_assist.db TENANT_CONFIG=/opt/basket-assist/config/tenant.toml \
     venv/bin/python -m basket_assist --sync --show"
   ```
   Выведет итоги синхронизации, таблицу и ближайшие матчи (ID матча, дата, время, соперник).
3. **Сверить с сайтом лиги** (ссылки — `team_url` в `config/tenant.toml`): дата, время, зал, соперник ближайших матчей.
   Структуру сайта и API не выдумывать — проверять реальным запросом (WebFetch / браузер).

## Частые расхождения
- **Матч без даты (АБЛ, черновик тура).** В базе `date_is_estimate = 1`, бот молчит (ни опроса, ни предупреждений), пока
  лига не опубликует дату. Это нормально.
- **Время не назначено.** Опрос не запускается; руководители получают «Время матча не назначено» раз в сутки в 10:00 по
  времени лиги. Если лига сообщила время вне сайта — руководитель пишет боту «время 25.10 18:30»
  (`Match.time_source = manual`); время с сайта, когда появится, главнее.
- **Перенос / смена времени** — по ADR 0007 это новый опрос: отметки сбрасываются, старый анонс удаляется, новый
  публикуется ниже сообщения о переносе. Проверь в логе `опрос по матчу N перезапущен`.
- **Игрок «нет в заявке на сезон»** — заявка на сезон синхронизируется ночью; дозаявку лига могла ещё не опубликовать.
  Сопоставление игроков с заявкой — у руководителей команды в боте («сопоставление»).
- **Изменился формат API** (адаптер падает с ошибкой разбора) — обнови образцы и адаптер: [fixtures.md](fixtures.md).
