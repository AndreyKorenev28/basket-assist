# Проверка бота VK на тестовой беседе

Одноразовая проверка (spike), не код сервиса. Цель — проверить на практике то, что не удалось подтвердить по документации (`docs/data-sources.md`, «VK — выводы»), и решить, нужен ли боту доступ «Администратор» в беседе команды.

## 1. Подготовка (делает владелец проекта)
1. **Создать сообщество** VK (тип — «Группа по интересам» или любой подходящий; название рабочее).
2. **Проверить переименование:** Управление → Настройки → изменить название → сохранить. Записать результат в таблицу ниже.
3. **Включить сообщения:** Управление → Сообщения → «Сообщения сообщества: включены».
4. **Включить возможности ботов:** Управление → Сообщения → Настройки для бота → «Возможности ботов: включены», отметить **«Разрешать добавлять сообщество в чаты»**.
5. **Long Poll:** Управление → Работа с API → Long Poll API → включить, версия **5.199**. На вкладке «Типы событий» отметить: входящее сообщение (`message_new`), действие с сообщением (`message_event`), разрешение/запрет сообщений (`message_allow`, `message_deny`).
6. **Ключ доступа:** Управление → Работа с API → Ключи доступа → создать ключ с правами **«Управление сообществом»** и **«Сообщения сообщества»**. Ключ — секрет, никому не пересылать и не вставлять в чат.
7. **Тестовая беседа:** создать новую беседу с 1–2 знакомыми (не основную беседу команды), добавить туда сообщество (в беседе: «Добавить участника» → вкладка/поиск сообществ).
8. Создать рядом со скриптом файл `.env` (он в `.gitignore`):
   ```
   VK_GROUP_TOKEN=<ключ из шага 6>
   VK_GROUP_ID=<числовой ID сообщества>
   ```
   ID видно в «Управление → Работа с API» или в адресе `vk.com/club<ID>`.

## 2. Запуск
```
cd D:\CLAUDE\projects\basket-assist\spikes\vk-probe
py probe.py
```
Скрипт работает, пока открыт терминал. Внешних библиотек не нужно. Все события и ответы VK пишутся в `events.jsonl` — его потом разберём вместе (файл содержит ID пользователей; в `.gitignore`, после разбора удалить).

## 3. Сценарий проверки
Команды в беседе — с упоминанием бота: `@club<ID> пост` (или через «@» выбрать сообщество).

**Этап А — доступ «только упоминания»** (по умолчанию после добавления):
| # | Действие | Что проверяем |
|---|---|---|
| А1 | Добавить бота в беседу | Пришло ли событие о добавлении (`action` в `message_new`) |
| А2 | Сообщение без упоминания бота | Видит ли его бот (ожидаем — нет) |
| А3 | `@бот пост` | Бот публикует анонс с тремя кнопками |
| А4 | Нажать кнопки с разных аккаунтов, с телефона (iOS/Android) и с компьютера | Приходит ли нажатие; всплывающее «Отмечено»; обновляется ли счётчик в анонсе |
| А5 | `@бот участники` | Ожидаем ошибку доступа |
| А6 | `@бот закреп` | Нужны ли права админа для закрепления |
| А7 | `@бот лс` (до того, как писали боту) | Может ли бот написать первым (ожидаем — нет) |
| А8 | Открыть ссылку `vk.me/club<ID>?ref=probe` из сообщения бота → «Начать» | Открывается ли диалог; приходит ли `ref`; потом снова `@бот лс` — теперь личка должна работать |

**Этап Б — выдать боту доступ «Администратор»** (настройки беседы → участники → сообщество → права) и повторить А3–А6.

**Этап В — редактирование старого сообщения:** через несколько часов / на следующий день нажать кнопку на старом анонсе — обновится ли счётчик (ошибка 909 «too old»?).
