# 0003. Канал MVP — VK (возврат)

- **Статус:** принято
- **Дата:** 2026-10-18
- **Заменяет:** [0002](0002-mvp-channel-telegram.md)

## Контекст
ADR 0002 перевёл MVP на Telegram, потому что бота сообщества VK не удавалось добавить в беседу: у владельца проекта (он же администратор сообщества) кнопки «Добавить/Пригласить в беседу» не было ни в вебе, ни в приложении.

Проверка владельца с другого аккаунта: **у участников, не являющихся администраторами сообщества, кнопка «Пригласить в чат» есть и работает** — бота пригласили в тестовую беседу.

## Решение
Канал MVP — снова **VK** (решение владельца проекта). Telegram и Max — после MVP через `ChannelAdapter`.

## Последствия
- Блокер снят. В инструкцию по подключению: **бота в беседу команды приглашает участник беседы, который не является администратором сообщества бота** (например, капитан, если он не админ сообщества). ⚠ Гипотеза «кнопку скрывают от админов сообщества» — по наблюдению на одном аккаунте; уточнить при подключении основной беседы.
- Остальные выводы по VK в силе: `docs/data-sources.md` («VK — выводы»), `spikes/vk-probe/README.md`.
- Наработки по Telegram (свойства Bot API в ADR 0002) пригодятся для адаптера Telegram после MVP.
