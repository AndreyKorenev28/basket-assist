# 0002. Канал MVP — Telegram (вместо VK)

- **Статус:** заменено ([0003](0003-mvp-channel-vk-return.md))
- **Дата:** 2026-10-18
- **Заменяет:** решение «Канал MVP — VK» (`open-questions.md`, 2026-10-18; отдельного ADR не было)

## Контекст
MVP планировался в VK. Проверка на тестовой беседе (`spikes/vk-probe/README.md`) показала:
- ✅ в личном диалоге с ботом работают ссылка с `ref`, согласие на сообщения, inline callback-кнопки, всплывающие ответы и редактирование анонса;
- ❌ **бота сообщества не удалось добавить в беседу** ни в вебе, ни в мобильном приложении: кнопки «Добавить в беседу», описанной в справке VK, нет, хотя настройка «Разрешать добавлять сообщество в чаты» включена. Без бота в беседе не работает основной сценарий — анонс и опрос в чате команды;
- риски VK из исследования: месячный лимит вызовов VK ID без верификации, ошибка 993 «Chat moved to MAX» (беседы могут переезжать в MAX), проверка «вы не робот» при переходе по `vk.me`.

## Решение
Канал MVP — **Telegram** (решение владельца проекта). VK и MAX — после MVP, через тот же `ChannelAdapter`.

## Что меняется
- Бот — Telegram-бот (создаётся через @BotFather), библиотека **aiogram 3**, получение обновлений — long polling (`getUpdates`), публичный HTTPS не нужен.
- Команде нужна группа Telegram (существующая или новая), куда добавляется бот.
- Модель домена почти не меняется: `MessengerAccount.channel = telegram`, опрос — inline-кнопки с `callback_data`.

## Ожидаемые свойства Telegram (по Bot API, ⚠ проверить на тестовой группе)
- Бота может добавить в группу участник с правом приглашать; отдельной настройки «разрешить добавлять» как в VK нет.
- **Privacy mode** (по умолчанию включён): в группе бот видит команды, упоминания и ответы на свои сообщения — этого достаточно; видеть всю переписку не нужно.
- Inline-кнопки в группе: нажатие приходит как `callback_query` с `from` (кто нажал); `answerCallbackQuery` — всплывающее уведомление; `editMessageText` — обновление анонса со счётчиком.
- **Список участников группы через Bot API получить нельзя** (есть только число участников и список админов). Значит, «кто не ответил» считается по списку игроков сервиса (подключились через `/start`, добавлены капитаном, заявки на сезон) — как вариант VK «без администратора».
- **Бот не может написать пользователю первым**, пока тот не нажал `/start`. Deep link `t.me/<bot>?start=<payload>` — аналог `ref` из VK.
- Закрепление сообщения требует прав администратора с `can_pin_messages`.

## Последствия
- ⚠ **Доступность Telegram в России и с российского VPS** — проверить: работают ли у игроков клиенты без ограничений и доступен ли `api.telegram.org` с FirstVDS. Если нет — пересмотреть.
- Данные игроков по-прежнему хранятся только в нашей БД на VPS в РФ (152-ФЗ). Через Telegram проходят только сообщения бота.
- Проделанная работа по VK не теряется: результаты в `notes/sources/vk-bots.md` и `spikes/vk-probe/`, сообщество «Basket Assist» (club242389357) остаётся для будущего адаптера VK. Ключ доступа VK можно отозвать.
- Следующий шаг: короткий spike на тестовой группе Telegram — проверить пункты выше.
