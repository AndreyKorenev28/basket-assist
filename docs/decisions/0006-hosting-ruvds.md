# 0006. Хостинг MVP — RUVDS START HIT SSD (вместо FirstVDS)

- **Статус:** принято
- **Дата:** 2026-10-19
- **Заменяет:** [0001](0001-hosting-firstvds.md)

## Контекст
FirstVDS «Прогрев» (ADR 0001) и следующий по цене VDSina «Стандартный» (150 ₽, Москва) при заказе оказались **без свободных ресурсов**. Свежее сравнение наличия на 2026-10-19 — `notes/vps-comparison.md`, раздел «Обновление 2026-10-19».

## Решение
**RUVDS START HIT SSD** — 1 ядро / 1 ГБ / 20 ГБ SSD, IPv4 в цене, **349 ₽/мес**, Debian 13 (Python 3.13 из коробки). Москва и СПб для тарифа были недоступны — выбран один из ДЦ в регионах РФ (для бота город не важен; 152-ФЗ — ДЦ в России).

Без платных опций: защита от DDoS не нужна (бот не принимает входящих подключений, снаружи открыт только SSH), бэкап — свой (`deploy/backup.sh`, ежедневно, 14 дней на сервере + копия на компьютер владельца «Забрать бэкап.cmd»).

## Последствия
- Развёртывание и эксплуатация — `deploy/README.md` (там же подводные камни этого образа: GRUB, DNS без IPv6, CRLF).
- Доступ — только SSH по ключу `~/.ssh/basket_assist_vps` (ключ без пароля, на компьютере владельца); вход по паролю отключён. Адрес сервера — `deploy/host.local` (вне git).
- Память: бот занимает ~65 МБ из 880 МБ; запас большой.
- ⚠ Поручение на обработку ПДн в оферте RUVDS не проверено (как и у FirstVDS — см. ADR 0001: согласие игроков и минимум ПДн обязательны). Перед целевым решением (чужие команды) — проверить оферту или переехать к провайдеру с поручением.
- Переезд при необходимости простой: один процесс + SQLite, `install.sh` + `deploy.sh --with-secrets --with-db`.
