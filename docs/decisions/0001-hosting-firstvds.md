# 0001. Хостинг MVP — FirstVDS «Прогрев»

- **Статус:** принято
- **Дата:** 2026-10-18

## Контекст
Сервис работает на VPS, бюджет минимальный, данные игроков — персональные данные граждан РФ (152-ФЗ), поэтому нужен российский ДЦ. Нагрузка MVP маленькая: один процесс (бот VK через Long Poll, планировщик, синхронизация с API двух лиг), SQLite, одна команда (~15–20 человек). Сравнение 11 провайдеров — `notes/vps-comparison.md`.

## Варианты
1. **FirstVDS «Прогрев»** — 299 ₽/мес, 1 ядро / 1 ГБ / NVMe, IPv4 включён, Москва. Минусы: бэкап платный (от 90 ₽), списание посуточное, канал 100 Мбит/с.
2. **Beget** (1/1/10 NVMe + IPv4) — ≈656 ₽/мес, бесплатные автобэкапы, СПб.
3. **Selectel Shared Line** — ≈729–1 059 ₽/мес, почасовая оплата, масштабирование без переустановки, сегмент под 152-ФЗ.

## Решение
FirstVDS «Прогрев» (решение владельца проекта). Ресурсов для MVP с запасом, цена минимальная. Бэкап SQLite — свой: cron + `sqlite3 .backup`, копия вне сервера.

## Персональные данные (проверено по документам FirstVDS, 2026-10-18)
Документы: [договор-оферта](https://firstvds.ru/docs/main/publichnyj_dogovor-oferta_ao_iot.pdf), [условия предоставления услуг](https://firstvds.ru/docs/main/usloviya_predostavleniya_uslug_ao_iot.pdf), [политика обработки ПДн](https://firstvds.ru/docs/main/politika_obrabotki_personalnyh_dannyh_ao_iot.pdf) (АО «ИОТ», ИНН 7731399513).
- **Поручения на обработку ПДн, которые клиент размещает на сервере (ч. 3 ст. 6 152-ФЗ), в публичных документах нет.** Политика ПДн касается только данных самих клиентов провайдера.
- Оферта, п. 5.5: если пользователь передаёт провайдеру ПДн третьих лиц, он гарантирует наличие письменных согласий.
- Условия, п. 2.7: запрещено хранить персональные данные третьих лиц, «кроме случаев, когда указанные лица прямо уполномочили Пользователя» → **согласие игроков обязательно**, независимо от 152-ФЗ.
- Оферта, п. 4.4.5: безопасность и резервное копирование данных — обязанность пользователя; п. 2.3: услуги «как есть».
- Оферта, п. 4.1.8: провайдер вправе использовать средства мониторинга, в том числе получать доступ к данным об использовании среды. Это ещё один довод хранить минимум ПДн.
- Вступление: договор «может быть заключен в письменной форме на иных условиях» → отдельное поручение теоретически можно запросить у поддержки.

## Последствия
- Для MVP (своя команда, ~20 человек, данные с согласия) риск приемлемый. Обязательно: согласие игрока при подключении к боту, минимум полей (без дат рождения, если они не нужны), шифрование бэкапов, удаление данных по запросу.
- **Перед целевым решением (сервис для чужих команд) решение пересмотреть**: запросить у FirstVDS поручение на обработку ПДн или переехать к провайдеру, который его даёт (Selectel, REG.RU «Москва ФЗ-152», Yandex Cloud). Переезд простой: один процесс + SQLite.
- ⚠ Это не юридическая консультация. Нужно ли поручение для голого IaaS, где провайдер не имеет доступа к данным, — спорный вопрос; для целевого решения стоит проконсультироваться с юристом.
- Перед оплатой проверить вручную: цену с НДС, диск по умолчанию, смену тарифа без переустановки (на странице тарифов цены рендерятся скриптом, автоматически подтвердить не удалось).
