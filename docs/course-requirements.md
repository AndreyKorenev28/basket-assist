# Требования курса к выпускному проекту

Скопировано владельцем с сайта курса 2026-10-21. Источник истины для подготовки к защите; описание самого проекта — `course-project.md`.

## Домашнее задание (сдаётся ссылкой на репозиторий)
1. Выбрать реальную рабочую задачу для автоматизации и оформить полное описание проекта по структуре из урока.
2. Начать разработку MVP в Claude Code: рабочая папка, план с Claude, первая версия кода, локальный запуск.
3. Создать GitHub-репозиторий, опубликовать проект **через GitHub CLI**, добавить **README со скриншотами** работающего проекта.
4. Сгенерировать **скилл** для проекта и опубликовать его **в том же репозитории**.

Результат: рабочий MVP на GitHub с оформленным README, скриншотами и скиллом.

## Онлайн-выпускной: выступление 3–5 минут
Структура:
1. Название и короткое описание — что это за проект.
2. Проблема — какую задачу решили.
3. Живая демонстрация — как проект работает (даже если локальный).
4. Результаты — что получается на выходе.
5. GitHub — показать репозиторий.
6. Планы — как развивать проект или какие следующие проекты делать с вайб-кодингом.

Если процесс долгий — показать готовый результат и объяснить, как он получен; финальный вывод подготовить заранее.

## Анкета для публикации проекта
1. Название проекта* — короткое и понятное.
2. Краткое описание* — 2–3 предложения: какую задачу решает, кому полезен, что пользователь получает на выходе.
3. Ссылка на скилл проекта* — файл или папка скилла в облаке (Google Диск, Яндекс Диск и т. п.), **доступ по ссылке открыт**.
4. Для кого полезен* — варианты: маркетологи, методисты и преподаватели, HR, менеджеры проектов, предприниматели, поддержка, аналитики, личное использование, другое (своё).
5. Что умеет проект* — кратко основные функции.
