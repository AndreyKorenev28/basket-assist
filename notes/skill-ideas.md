# Кандидаты на скилл проекта

Скилл создаётся по завершении MVP. Сюда по ходу работы записываются повторяющиеся операции, которые стоит упаковать.

- **Добавить адаптер новой платформы лиги** — исследовать сайт (как для АБЛ/МЛБЛ: `notes/sources/<лига>/`), сохранить образцы, реализовать `PlatformAdapter`, контрактные тесты.
- **Проверить синхронизацию с лигой** — запросить расписание/заявку на сезон для выступления, сравнить с БД, показать расхождения.
- **Развернуть / обновить сервис на VPS** — шаги деплоя, проверка, откат.
- **Обновить фикстуры API лиг** — `scripts/capture_fixtures.py` + проверка обезличивания + прогон контрактных тестов; при изменении формата — поправить адаптер.
