# Сравнение VPS-провайдеров для basket-assist

Дата проверки всех цифр: **2026-10-18** (если не указано иное). Источник каждой цифры — официальная страница тарифов провайдера (ссылка в таблице и в разделе «Источники»).
Обозначения: «⚠ не проверено» — значение не удалось подтвердить на официальной странице; «(расчёт)» — сумма, которую я посчитал из официальных поштучных цен.

## Профиль нагрузки (для чего подбираем)

- Один процесс на Python 3.13: бот VK (Bots Long Poll), планировщик и опрос двух JSON API лиг раз в 1–2 часа. База — SQLite.
- MVP: одна команда, 15–20 пользователей. Нагрузка почти нулевая: процесс занимает порядка 100–200 МБ RAM, CPU простаивает. Хватит **1 vCPU (можно долю ядра) / 1 ГБ RAM / 10 ГБ диска**.
- Рост до сотен команд: всё ещё один процесс. Узкие места — RAM и запись в SQLite, а не CPU. Хватит 1–2 vCPU / 2 ГБ.
- **IPv4.** Long Poll не требует входящих соединений, но серверу нужен *исходящий* доступ в интернет к api.vk.com и к API лиг. В облаках (Selectel, REG.RU, Yandex, VK Cloud, Cloud.ru) ВМ без публичного IP в интернет не выходит: нужен NAT/SNAT-шлюз, а он стоит не дешевле адреса (у Selectel облачный роутер — 200 ₽/мес, а IP — 189,57 ₽/мес). **Тарифа, который без IPv4 реально дешевле, я не нашёл.** У классических VPS (FirstVDS, Hostkey, RUVDS, Timeweb) IPv4 обычно входит в цену.

## Плюсы и минусы

- **FirstVDS** (ООО «Первый», на рынке с 2002 г., по данным сайта). Плюсы: самый дешёвый годный тариф (299 ₽), IPv4 бесплатно, ДЦ в Москве (WEB DC, IXcellerate Tier III), оплата картой и СБП («Система быстрых платежей», SberPay, ЮMoney; так в FAQ страницы). Минусы: у «Прогрева» канал 100 Мбит/с (для бота хватает), не больше 5 серверов на аккаунт, на него не действуют акции. Бэкап платный (от 90 ₽). Почасовой оплаты нет (списание посуточное).
- **RUVDS**. Плюсы: дёшево (349 ₽), много ДЦ в РФ, на сайте сказано «Провайдер лицензирован ФСТЭК», есть раздел «Серверы 152-ФЗ» и публичная оферта. Минусы: линейка «Старт» временно недоступна в части ДЦ, процессор 2,2 ГГц, с 01.07.2026 цены выросли.
- **Hostkey**. Плюсы: 490 ₽ за 1/1/40 с IPv4. Минусы: локация тарифа не подтверждена (у компании много зарубежных ДЦ). Для 152-ФЗ нужно явно выбирать Москву (DataPro).
- **Beget** (СПб, крупный шаред-хостер). Плюсы: **бесплатные автоматические бэкапы**, NVMe, гибкая конфигурация от 1/1/10, есть страница [beget.com/ru/cloud/152fz](https://beget.com/ru/cloud/152fz), простой интерфейс. Минусы: IPv4 платный (150 ₽), только СПб.
- **REG.RU**. Плюсы: почасовая оплата, отдельный аттестованный регион «Москва ФЗ-152», бэкапы и снапшоты в панели. Минусы: дороже FirstVDS и RUVDS, на стандартном тарифе SATA SSD. В момент проверки для одного из образов показывалось «нет доступных тарифов», то есть возможны локальные дефициты.
- **Selectel** (СПб/Москва, Tier III, одна из самых надёжных площадок РФ по репутации). Плюсы: зрелое облако, почасовая оплата, менять vCPU и RAM можно без переустановки, отдельный 152-ФЗ-сегмент для облачных серверов ([docs](https://docs.selectel.ru/cloud/servers/about/fz-cloud-server/)), API и Terraform. Минусы: облако выходит дороже VDS. **Новая линейка VDS за 200 ₽ сейчас распродана** («Все конфигурации распроданы»), и в FAQ прямо написано: VDS «не соответствует» 152-ФЗ, поручение на обработку ПДн «не предоставляется».
- **Timeweb Cloud**. Плюсы: почасовая оплата, удобная панель, раздел «Соответствие 152-ФЗ» ([/solutions/152fz](https://timeweb.cloud/solutions/152fz)), ДЦ в Москве, СПб, Новосибирске. Минусы: в 2026 г. базовые цены заметно выше конкурентов (1 380 ₽ за 1/1/15).
- **Yandex Cloud / VK Cloud / Cloud.ru**. Плюсы: «большие» облака с высокой надёжностью и аттестованными сегментами. Минусы: для одного маленького бота это переплата в 3–5 раз. Free tier Cloud.ru новым пользователям уже недоступен.

## Договор-оферта и 152-ФЗ

- **Локализация** (ч. 5 ст. 18 152-ФЗ — хранить ПДн граждан РФ в базах на территории РФ) выполняется любым из перечисленных вариантов, если выбран **российский ДЦ**. Все рассмотренные провайдеры — российские юрлица (реквизиты на сайтах; ИНН я отдельно не проверял, ⚠).
- **Аттестованный (УЗ-) сегмент** для маленького любительского бота обычно не обязателен. Обязанности оператора ПДн (уведомление Роскомнадзора, политика обработки, согласия пользователей) лежат на владельце бота независимо от хостера. Это не юридическая консультация.
- **Оферта / поручение на обработку ПДн**:
  - Selectel VDS: поручение **не предоставляется**, «не соответствует» 152-ФЗ (FAQ на странице VDS). Облачные серверы Selectel 152-ФЗ поддерживают (страница документации fz-cloud-server). Условия поручения для них ⚠ не проверены.
  - REG.RU: есть отдельный регион «Москва ФЗ-152». Условия договора ⚠.
  - Timeweb, Beget, RUVDS: у каждого есть раздел про 152-ФЗ (ссылки выше). Текст оферты и наличие поручения в базовом тарифе **⚠ не проверены**.
  - FirstVDS, Hostkey, Aeza, Yandex, VK Cloud, Cloud.ru: **⚠ не проверено**.
- Перед покупкой стоит открыть оферту выбранного провайдера и поискать в ней «персональные данные» / «поручение».

## Рекомендация

1. **Самый дешёвый годный — FirstVDS «Прогрев», 299 ₽/мес.** 1 ядро / 1 ГБ / NVMe, IPv4 включён, Москва. Для MVP (один процесс, 15–20 человек) ресурсов с большим запасом. Бэкапы SQLite можно делать самому: cron + `sqlite3 .backup` и копия в S3 или к себе. Тогда платный бэкап не нужен. Запасной вариант той же цены — RUVDS START HIT SSD (349 ₽).
2. **Оптимальный — Beget, произвольная конфигурация 1/1/10 NVMe + IPv4, ≈656 ₽/мес.** На ~350 ₽ дороже, зато **автоматические бэкапы бесплатно**: для SQLite на одном сервере это главная страховка. Ресурсы наращиваются ползунками, ДЦ в СПб, есть страница про 152-ФЗ. Альтернатива — REG.RU Std C1-M1-D10 (≈678 ₽) с почасовой оплатой и возможностью позже переехать в регион «Москва ФЗ-152».
3. **Запас на рост — Selectel, облачный сервер Shared Line, ≈729 ₽/мес (10 % / 1 ГБ / 10 ГБ) → ≈1 059 ₽ (10 % / 2 ГБ / 15 ГБ).** Почасовая оплата. Долю CPU (10 → 20 → 50 → 100 %) и RAM можно поднимать без переустановки, снапшоты и бэкапы дешёвые, есть 152-ФЗ-сегмент, сильная репутация по стабильности. Подойдёт, когда команд станут десятки или сотни. Если линейку Selectel VDS (200 ₽) вернут в продажу, она дешевле, но для ПДн не годится: Selectel сам пишет, что она не соответствует 152-ФЗ.

Timeweb, Yandex Cloud, VK Cloud и Cloud.ru для этой задачи не рекомендую: те же возможности стоят в 2–5 раз дороже.

## Что не удалось проверить (⚠)

- FirstVDS «Прогрев»: размер диска по умолчанию (на витрине «до 40 ГБ»), почасовая или посуточная тарификация, смена тарифа без переустановки, НДС.
- RUVDS: входит ли IPv4 в START HIT SSD, в каких ДЦ этот тариф сейчас доступен, единица цены «бэкап данных 7 ₽».
- Hostkey vm.pico: локация (РФ или Нидерланды).
- Beget: точная модель списания (почасовая или посуточная), цена конфигурации 1/2/20 (калькулятор не пересчитался).
- Selectel VDS: входит ли IPv4 в 200 ₽ и когда линейка вернётся в продажу.
- Timeweb: доступность тарифов Cloud EKB/KZN (350 ₽), цены в Москве и Новосибирске для линейки Premium.
- Yandex Cloud: цена сетевых дисков и минимальное число vCPU на платформе Ice Lake.
- Cloud.ru (платные ВМ), Aeza: цены не получены.
- Условия договоров-оферт и поручения на обработку ПДн у всех, кроме Selectel VDS.
